# ExScim

**ExScim** is an open-source organization focused on **SCIM (System for Cross-domain Identity Management)** projects written in **Elixir**.

The organization hosts libraries and supporting tools related to implementing and working with the SCIM specification.

If you are looking for the main SCIM library, see **[ex_scim](https://github.com/ExScim/ex_scim)** for details.
